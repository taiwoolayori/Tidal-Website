# Olayori Central public pages — deployment

This update adds three public pages to the existing Tidal Crest static site:

- `olayori-central.html`
- `privacy.html`
- `data-deletion.html`

It also adds discreet footer links to these pages across the existing site and extends `styles.css` with matching black/gold styling.

## Publish

Commit and push the updated files to the GitHub repository that currently publishes `tidalcrestgroup.com`.

After GitHub Pages deploys, verify these URLs:

- `https://tidalcrestgroup.com/olayori-central.html`
- `https://tidalcrestgroup.com/privacy.html`
- `https://tidalcrestgroup.com/data-deletion.html`

Use `https://tidalcrestgroup.com/privacy.html` for the Plaid privacy-policy URL field after confirming it loads publicly over HTTPS.

No DNS changes are required if the existing site is already publishing correctly at `tidalcrestgroup.com`.
